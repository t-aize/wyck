# Contributing

Projet perso, privé, solo (cf. [README](README.md)) — pas de contributions externes attendues,
pas de process de PR/review formalisé. Ce fichier existe juste pour éviter un dépôt "vide" côté
GitHub, pas comme une invitation à contribuer.

Pour toi-même : `bun install`, `bun run typecheck`, `bun run lint` avant de commit.
