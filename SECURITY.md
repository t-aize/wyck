# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/t-aize/wyck/security/advisories/new).
Include a description, reproduction steps, and the impact you expect. You can expect an initial
response within a few days.

Wyck is intended to connect to trading accounts. Never share API keys, tokens, or account
credentials in an issue, a pull request, or a report.
