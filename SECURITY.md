# Security Policy

Projet perso, privé, solo (cf. [README](README.md)) — pas de programme de sécurité formalisé, pas
de bug bounty.

Le seul secret sensible est le token MCP cTrader stocké (chiffré) dans `~/.aurum/config.json` — ne
jamais le commit ni le partager. En cas de doute sur une faille, ne pas ouvrir d'issue publique avec
des détails sensibles ; corriger/contacter directement l'auteur.
