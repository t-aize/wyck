# Support

This is a small project maintained in spare time. Support is best-effort, and there is no
guaranteed response time.

## Where to go

| I want to...                        | Go to                                             |
| ----------------------------------- | ------------------------------------------------- |
| Report a bug                        | Open an issue with the **Bug report** form        |
| Suggest a feature                   | Open an issue with the **Feature request** form   |
| Report a security problem           | Follow [SECURITY.md](SECURITY.md), never a public issue |
| Report a conduct problem            | Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)   |
| Contribute code                     | Read [CONTRIBUTING.md](CONTRIBUTING.md)           |
| Understand how something works      | The README and the documentation in the source (`cargo doc --open`) |

## Before you ask

- Read the README and the documentation. Run `cargo doc --open` for the API docs.
- Search the open and closed issues.
- Try the latest release or the latest commit on the default branch.

## What helps to get an answer

- A short description of what you are trying to do.
- The version or commit, your operating system, and `rustc --version`.
- The exact error output, as text.
- A minimal way to reproduce the problem.
- Secrets removed: tokens, keys, and account identifiers must never be posted.

## What this project cannot help with

- General Rust, tooling, or operating system questions.
- Problems with third-party services or accounts. Contact the provider.
- Custom development or private consulting.

## Supporting the project

If the project is useful to you, you can sponsor the maintainer through the **Sponsor**
button on the repository. Sponsoring does not buy priority support.
