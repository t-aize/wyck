## Sizes

- No Wyck size enum. The 22 hits for `Size::` are `BoxSize` and `VolumeSize`. Control size comes from gpui-kit `.small()`, `.xsmall()`, `.compact()` (75 lines in 20 files).
- `wyck-ui/src/tokens.rs:78-96` has `height::{tiny 20, compact 24, control 28, large 34}` times a global scale (`SCALE: AtomicU32`). gpui-component `Size` gives XSmall 20, Small 24, Medium and Large 32 for buttons (`button/button.rs:626-640`). `button::primary` and `secondary` use `.large()` (32) while `tokens::height::control()` is 28.
- Text size always through `tokens::text::*` (216 calls, 0 literal). `tokens::height` used 67 times.
- Remaining literal heights: `dashboard/header.rs:636` `.h(px(32.))`, `title_bar.rs:80,101` (25.0, probably platform imposed, not verified), `trading/panel/view.rs:1230` `22.`, `wyck-ui/confirm.rs:76` `22.0 * rows`.
- `tokens::menu::*` widths are plain `const f32` and are not scaled with the UI scale.

- Color constructors: 44 `rgb(`, `rgba(`, `hsla(` in the app (`settings_hub/look.rs` 9, `dashboard/marks.rs` 7, `indicators/editor/providers.rs` 6, `chart/overlay.rs` 6, `chart/paint.rs` 3). Many are transparent borders `rgba(0)` (`overlay.rs:764`, `editor_dock.rs:139`, `trade.rs:749`, `multichart/mod.rs:1182,1236`, `panel/view.rs:222`, `console.rs:24`). `dashboard/marks.rs` holds 153 hex brand colors (legitimate).

## GPUI architecture

- State: entities (`Account`, `Alerts`, `MultiChart`, `Workspace`), view fields (`Dashboard.conn`, `catalog`, `details`), globals (`appearance::State`, `indicators::Service`, `updates::Service`, `PendingSummary`, color picker and modal in `wyck-ui`), statics (`RUNTIME`, `PATHS` `main.rs:142`, `SPEAKER` `sound.rs:333`, `CATALOG` `layouts.rs:152`, `SCALE` `tokens.rs:13`).
- `cx.notify()` bursts: 29 in `ticket/mod.rs`, 22 in `indicators/editor/mod.rs`, 18 in `multichart/mod.rs`. Hot path: one `Event::Spot` is dispatched to four receivers (`dashboard/mod.rs:479-487`); `Account` notifies when a tracked symbol moves (`account.rs:794`) and three observers react (`panel/mod.rs:105`, `ticket/mod.rs:244`, `dashboard/mod.rs:281`). `Chart::set_lines` compares before notifying (`chart/mod.rs:813`), which limits the damage.
- Work in `render`: `trading/panel/view.rs:1534-1551` rebuilds the table and calls `set_rows`; `ticket/view.rs:574-582` runs `sync_link`, `request_atr`, `plan()`, `apply_defaults` (a mutation) and `plan()` again; `multichart/mod.rs:1117-1137` updates entities per slot; `dashboard/header.rs:239-251` creates an `InputState` and a subscription once, guarded by `tf_custom.is_none()`.
- Subscriptions: 61 `observe` or `subscribe`; most stored in `Vec<Subscription>` or `_observe`; `.detach()` on long-lived entities (`dashboard/mod.rs:250-298`, `editor_dock.rs:37`, `trade.rs:64`). No dropped subscription found; exhaustive analysis not done.
- Background task: `chart/mod.rs:536` re-runs `ensure_flow` and `request_drawing_atr` every second per chart, even without change.
- Test support: no `#[gpui::test]` anywhere; `Account` needs a gpui `Context` and a concrete `Session`.
