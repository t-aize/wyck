# wyck-chart

- Real role: chart models without any rendering engine: series, timeframes, 50 studies (indicators) plus Rhai scripts, drawings, scene command list, export, chart type transforms. Matches the description "Chart models, calculations and studies", but mixes two domains (chart and indicators) and holds trading and I/O pieces.
- Type: lib, edition 2024, no features.
- Internal dependencies: `wyck-openapi` (types only: `Bar`, `Tick`, `Quote`, `Period`), `wyck-config` (`export/store.rs` presets, `study/custom/library.rs` scripts). Incoming: `wyck`. No `gpui`.
- External dependencies: `chrono`, `chrono-tz`, `rhai`, `serde`, `serde_json`, `thiserror`, `toml`; dev `tempfile`. `proptest` is not used here although available.
- Size: 59 files, 37,252 lines (non-test about 32,589 lines of code). Files over 800 lines: `drawing/book.rs` 2740 (1655 non-test), `study/mod.rs` 2053 (1750), `drawing/extras.rs` 2039, `drawing/model.rs` 1936, `drawing/geometry.rs` 1936, `export.rs` 1876, `scene/mod.rs` 1446, `transform.rs` 1048, `study/custom/api.rs` 1042, `figures.rs` 987, `study/extended.rs` 965, `tpo.rs` 937, `study/custom/library.rs` 926, `custom/run.rs` 868, `math.rs` 834, `footprint.rs` 800.
- Public API: 24 `pub mod`, 531 `pub fn`. Candidates for narrowing: `study::intern`, `study::math`, `drawing::extras`, `drawing::figures` (each referenced once from the app). Item level check not done.
- Cohesion: `data`, `timeframe`, `study/` (spec, config, compute, extended, math, profile, catalog, atr_stop, intern, custom), `drawing/` (model, geometry, extras, figures, book, position, look, decor), `scene/` (build, series, studies, footprint, tpo, price, geometry, cmd, color), `export` and `export/store`, `transform`, `volume`, `footprint`, `flow`, `tpo`, `axis`, `view`, `projection`, `display`, `settings`, `options`, `zone`, `format`, `text_scale`, `defaults`, `lines`.
