# wyck-openapi

- Real role: cTrader Open API client (JSON over WebSocket), session supervisor, OAuth, and a large layer of trading domain (types, calculations, account book). Intended role (from the name and `Cargo.toml` description): "client, messages and trading calculations".
- Type: lib, edition 2024, feature `client` (default; `async-trait`, `futures-util`, `reqwest`, `secrecy`, `tokio`, `tokio-tungstenite`, `uuid`). Without it: messages, market types and calculations only. 4 examples (`accounts`, `prices`, `history`, `demo_order`).
- Internal dependencies: none outgoing; incoming from `wyck` (feature `client`) and `wyck-chart` (no `client`).
- External dependencies: `chrono-tz` is non optional but only used by `market/hours.rs`. No unused dependency measured (tools missing, T-004).
- Size: 59 files, 17,540 lines (src 12,213, tests 5,062). Largest: `tests/live.rs` 1339, `session/mod.rs` 1109, `tests/session.rs` 959, `transport/connection.rs` 808, `account/types.rs` 789, `account/book.rs` 782.
- Public API that should be `pub(crate)` or hidden: `transport::*` (doc-hidden, public only for integration tests, `lib.rs:166-169`); `event_from` (`event.rs:86-88`); unused outside: `UNITS_PER_PRICE`, `Contract::format_price`, `config::JSON_PORT`, `SymbolTable::{id_of,name_of,starting_with}`, `DepthBook::{best_bid,best_ask,bid_size,ask_size}`, `Client::{refresh_tokens,ctid_profile}`, `AccountClient::logout`, `MarginClient::{margin_calls,dynamic_leverage}`, several `AccountDataClient` methods, `Session::wait_ready`. These are SDK surface with tests, not dead code in the strict sense.
- Cohesion: `transport/` (wire, connection, rate limit, messages), `session/` (supervisor, backoff, token store), `auth/` (oauth, callback), `market/` (price, bars, ticks, symbols, hours, quotes, live, depth, history, client), `account/` (types, book, requests, client), `trading/` (contract, requests, events, client), `margin/`, `event.rs`, `error.rs`, `config.rs`, `handle.rs`. No catch-all module.
- Misplaced responsibilities: `trading/contract.rs` (sizing, risk, conversion chain) -> `wyck-trading`; `account/book.rs` with UI text (`Tone`, `Notice`, `NoticeAction`, `explain` `:443`, `refusal` `:487-571`, `describe` `:574-603`) -> split, text to the app; `market/{price,bars,ticks,symbols,hours}` -> `wyck-core`; `SpotTracker`, `LiveBarTracker`, `DepthBook`, `SymbolTable` -> derived state, `wyck-trading` or `wyck-core`; `Period` shared with `wyck-chart` -> core.
- Internal redundancy: scale conversion in `price.rs:21,31,48,76`, `types.rs:212,218`, `contract.rs:102-138` (second `PRICE_DIGITS = 5` and a second `format_price`); `money_digits` copied in 6 structs.
- External redundancy: `TokenSet` vs `wyck_config::OpenApiTokens`; `format_price` vs `wyck-chart` `export.rs:1438 price_text`.
- Dead code: `#[allow]` none in `src/`; `tests/support/mod.rs:6` allows `dead_code`.
- Quality: 1 `expect` outside tests (`auth/oauth.rs:76`, constant URL); no `println!` outside examples and tests; no TODO; `#![forbid(unsafe_code)]`; `Arc<Mutex<Option<JoinHandle>>>` (`session/mod.rs:251`), std `Mutex` for `pending`, `registry`, `tokens`, `RwLock<Option<Client>>`; connection task handle dropped on purpose (`connection.rs:274`).
- Errors: `thiserror`, `#[non_exhaustive] Error` and `ErrorKind`; server code is a `String`.
- Concurrency: channels bounded in production (`mpsc::channel(256)`, `broadcast` 8192); no lock held across `.await` in what was read; refresh deliberately not cancellable.
- Docs: doc plus comment about 30 % of code lines; about 80 constant docs repeat the name (`wire.rs:31-218`); `lib.rs` crate doc is long and useful; orphan "MCP servers" comment (`bars.rs:15`).
- Tests: unit tests nearly everywhere, 9 integration files against a scripted local server, 16 proptest properties, 13 ignored live tests guarded by `WYCK_OPENAPI_ALLOW_LIVE_TRADING`. No in-memory fake transport.
- Verdict: clean, then split by responsibility. Keep transport, session, auth, error and the test harness; move domain out; harden per `PLAN.md` 4.1; split `session/mod.rs` (`supervise`, `serve`, subscribe API, refresh) and `connection.rs` (client lifecycle, request machinery, run loop).
